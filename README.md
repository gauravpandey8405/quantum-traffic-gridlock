# Quantum Traffic Gridlock - QAOA Pipeline
Team Submission for IBM Qiskit Fall Fest 2026

## Setup Instructions
1. Create and activate virtual environment:
   python -m venv qenv
   .\qenv\Scripts\Activate.ps1
2. Install requirements:
   pip install -r requirements.txt

## Running the Pipeline
Run the runnable pipeline using the required CLI arguments:
python run.py --scenario scenario_R.json --seed 42 --out ./
